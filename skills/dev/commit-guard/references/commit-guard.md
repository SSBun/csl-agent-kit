# 提交保护边界

`commit-guard` 拥有检查逻辑与规则语义。内置规则 `inner:code-inline-review-commit` 使用 Agent Hooks 的 `before-tool` / `run-script`，默认启用；保留历史 ID 以尊重已有启用／禁用设置。注册文件及薄入口留在 agent-hooks 的受控目录，薄入口调用本 Skill 的 `scripts/check-commit.js`。它不依赖用户本次是否调用任何 Skill。通过 agent-hooks CLI 查看实际宿主状态，升级 Pi 扩展后需 `/reload` 或重新启动会话。

## 判定

对可见的 `git commit` 调用做受限参数解析；其他 Git 子命令直接放行。不执行传入的 shell 文本来探测效果。支持 `git -C <目录> commit -m <消息>`、`-F`、`--amend --no-edit` 等显式暂存提交流程。检查实际仓库根目录 `.csl-agent-kit/` 之外整个 index 的文件内容，包含未改动行；从子目录调用也扫描相同范围。根目录 `.csl-agent-kit/` 下的全部内容豁免审查标记检查，保留任务证据和测试材料原文；同名嵌套目录及相似前缀目录仍检查。匹配由 `@code` 与 `-review` 无间隔拼接得到的保留字符串；使用固定字符串搜索，区分大小写。任何位置命中均拒绝，不依赖注释前缀、文件类型或 begin/end 的完整性。

| 情况 | 行为 |
| --- | --- |
| index 干净，工作区或未跟踪文件有说明 | 放行，不清理工作区 |
| 根目录 `.csl-agent-kit/` 及其子目录中的暂存内容有保留字符串 | 豁免审查标记检查，保留原文 |
| 豁免目录外的 index 任意位置有保留字符串，包括字符串、行尾、文档示例和二进制 | 阻断并报告绝对文件路径与行号 |
| 冲突、Git 失败、超时或检查输出超限 | 阻断并说明检查未完成 |
| `commit -a`、路径提交、交互暂存，或包含 `git commit` 的组合命令、环境变量前缀、条件语句、重定向、变量展开 | 阻断，要求拆分为显式暂存和独立提交；here-document 结束后的可见 `git commit` 也检查 |
| 除 `commit` 外的所有 Git 子命令，包括 `stash`、`merge`、`rebase`、`cherry-pick`、`revert`、`am` 和别名 | 直接放行，不检查是否产生提交对象；它们的参数、包装或组合形式也不因本规则被阻断，除非其中另有可见的 `git commit` |

hook 不修改工作区、index、Git 配置或 hooksPath，不自行清理或重新暂存。需要修复时请用户修复或明确授权 Agent 清理；不能重试另一种包装命令绕过。

## 宿主与故障

Pi 的 `tool_call` 将检查器返回的阻断结果交给宿主；Codex/Claude Code 使用原生 PreToolUse 返回码。`on-error: block` 使本规则的脚本启动失败、超时和非零退出也阻断调用；其他普通脚本保留原有尽力执行语义。

规则源或启用配置损坏必须修复后再声称保护生效。宿主只加载旧版本、禁用规则、未安装插件或不经过对应工具调用时，没有保护保证。外部控制面可用 `csl-agent-kit agent-hooks disable inner:code-inline-review-commit` 恢复故障；Agent 不得为了完成提交自行禁用规则。

## 明确限制

这是 Agent 的提交前检查，不是 Git 服务端或操作系统沙箱。它不检查外部终端/GUI，也无法证明任意 Python/Node/shell 脚本、远端工具、隐藏 shell 函数或扩展私自执行的 Git 调用。Agent 必须直接调用 Git，不得通过这些方式绕过。

检查与 Git 真正创建提交之间不持有跨进程锁。不得把暂存/修改 index 与提交并行调用，也不要在检查期间由其他进程改变 index；原生 Git hooks 也可能改变内容。第一版不声称消除了这类竞态或对恶意绕过提供绝对保证。需要跨客户端和并发写入的强制保障时，应另行设计 Git/CI 层检查。

标记是保留协议，除根目录 `.csl-agent-kit/` 的明确豁免外，同形文本一律阻断，不区分是否真正的审查说明。协议实现、文档和夹具用占位符、转义或拆分字符串表示；不提供其他文件或扩展名豁免。说明的生成、维护和授权清理由 `code-inline-review` 负责，本检查器不承担这些职责。检测只保证对暂存字节中完整保留字符串的匹配，不声称识别去掉标记后的自然语言或编码／变形后的文本；不得删除或改写标记来夹带真实临时说明。

当前不检查 `git push` 的待推送提交历史，不实现密钥扫描或通用代码质量规则。提交检查通过不能作为这些内容已通过检查的证据。
