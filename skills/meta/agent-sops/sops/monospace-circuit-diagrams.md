# SOP: 等宽字符电路图

## 1. 目的

用固定显示列绘制可读的中英文字符电路图，同时保证连线语义明确。先确定电气连接，再排版，最后分别检查列对齐与连接关系；不能把“看着整齐”当成电路正确的证据。

## 2. 适用范围

适用聊天和 Markdown 中的小型电路说明、模块连接图，以及用户指出的字符电路错位修正。允许图内中英文混排，不以删除中文代替对齐。

不替代正式原理图、PCB、仿真、ERC 或器件数据手册。复杂到无法清楚表达的电路先拆成局部图；只有用户接受更换输出形式后，才改为图形或原生设计文件。

## 3. 绘图约定

### 显示列宽

- 先形成普通字符底稿：只用普通 ASCII 空格与 LF 换行，不用 Tab、全角空格、不换行空格或依赖行尾空格的排版。Pi 中通过 `render_ansi` 输出样式版；Markdown 文档及纯文本回退使用独立的 `text` 代码块，不写入原始 ESC 控制字符。
- ANSI SGR 样式序列不占显示列。先核对去除样式后的底稿，再加颜色；不得把转义序列的字符串长度算入列宽，也不得用光标移动指令弥补错位。
- 默认 ASCII 字符占一列，常用中日韩宽字符占两列。计算显示宽度，不用字节数、字符串长度或 Unicode 码点数量代替。
- 组合字符、Emoji、东亚歧义宽度字符可能不符合上述简化模型。图内避免使用；必要时按目标终端的实际宽度规则验证，不能一概宣称“所有非 ASCII 都是两列”。
- 结构线默认使用 ASCII。中文可以放在框内、标题、端口名或旁注中；中文右边还有边框或导线时，必须按显示列补齐。
- 每行默认不超过 80 个显示列；已知终端更窄时按可用宽度收紧。避免宿主自动换行，必要时缩短标签或拆图。
- 用户已说明使用等宽字体时，先检查自身的列计算、断线和错位，不未经检查就归因于字体。没有目标终端截图或直接观察时，只声称完成列宽检查，不声称已验证实际渲染。

### 符号与连接

| 表示 | 含义与限制 |
|---|---|
| `-`、`|` | 水平、垂直导线；必须连续接到目标端口。 |
| `o` | 电气连接节点，所有 T 接与多支路汇接都显式标记。 |
| `+` | 方框角或单根导线转角；不表示多支路连接。 |
| `[R1]` | 串联电阻等简化元件，必须在说明中定义器件类型。 |
| 上下两行 `---` | 垂直无极性电容的两块极板；上下导线对准极板中心，中间不画贯通导线。 |
| `GND`、网络名 | 同名表示同一网络；不同地如 `AGND`、`PGND`、隔离两侧地不得未经说明合并。 |

- 默认避开无连接的交叉线：改走线或使用明确的同名网络标签，不用含糊的交叉符号让用户猜是否相连。
- 方框边缘是器件外形，不是导线；框内标注端口，外部导线只接指定端口。区分功能连接图与物理封装引脚图。
- 晶体管须标明类型和端子：MOS 管用 G/D/S，BJT 用 B/C/E；不能只画一个框再让读者猜引脚。
- 二极管明确 A/K，极性电容明确正负端，电源明确极性。复杂符号不能可靠表达时使用带端子标签的器件框，不编造易混淆符号。
- 说明性箭头不是导线；电流方向标注还需区分常规电流与电子运动方向。

### 信息层次与语义配色

- 先明确图要回答的问题：供电如何分配、信号如何连接、反馈如何返回，或保护元件如何工作。布局优先让主要路径从左到右、回流在下方；不为套用布局制造交叉或改变拓扑。
- 需要追踪电流或实际接线时，优先画连续路径与回路；仅为缩窄图幅或拆分功能块时使用同名网络标签，并说明“同名网络相连”。供电路径不能只画正极而遗漏回流；省略部分须明确标注。
- 只标注理解当前问题所需的位号、端子、网络、额定电压和必要方向。未确认的参数写“按型号规格”，不能把常用示例值冒充通用额定值。多路电源尤其要区分供电电压与信号电平。
- 颜色回答“这条线属于什么网络或作用”，不用于装饰整个器件框。器件外形、元件本体与普通说明用默认前景色；导线、连接点与相应网络标签一致着色，进入电阻、稳压器等器件后按各端实际网络分别处理。

| 语义 | 建议样式 | 必须保留的文字信息 |
|---|---|---|
| 主供电轨 | 红色 `91` | `VIN`、`+5V` 等真实网络名与已知电压 |
| 另一供电轨／稳压输出 | 黄色 `93` | `+3V3`、`VOUT` 等；不能只靠颜色区分电压 |
| 控制／数据／模拟信号 | 青色 `96` | `PWM`、`SDA`、`SIG_OUT` 等，方向明确时另行说明 |
| 返回信号／反馈 | 洋红 `95`，仅确有第二种路径时使用 | `FB`、`RX` 等；无此需求不增加颜色 |
| 地／回流 | 默认前景或对比度足够的灰色 `90` | `GND`、`AGND`、`PGND`、隔离域名称 |
| 风险说明 | 默认前景加粗 `1` | “不可相连”“电平需匹配”等具体文字，不用闪烁或整图警告色 |

- 同一网络在整图与拆分图中使用同一配色；同一颜色可以复用给同类网络，但**同色不表示电气相连**。不同地仍须用独立名称与隔离边界区分；未经确认不共地。负电源也必须显示负号，红色不等同于正电压。
- 图例只列本图实际用到的颜色与网络；颜色很多时先拆图或用标签区分，不堆叠彩虹配色。去掉所有 ANSI 后，连接、极性、方向与警告仍须清楚。
- 尊重终端原有背景，不主动铺设背景色，不整图反色。深色底上灰色地线过暗时改用默认前景；不能为了坚持配色表牺牲回流路径的可读性。终端主题决定标准颜色的具体色值，颜色不是现实线缆颜色规范。

### Pi ANSI 输出契约

- 工具可用且用户未要求纯文本时，调用 `render_ansi({ text: ... })` 直接在会话中展示；不使用 Bash `printf` 代替，不要求用户复制命令，不生成图片或 KiCad 文件，也不只贴出含转义码的代码块。
- `text` 中传入真实 ESC 字符；工具 JSON 用 `\u001b` 表示 ESC，例如 `\u001b[91m` 开启红色、`\u001b[0m` 重置。不要传入字面量 `\\x1b` 或双重转义的 `\\u001b`。用 `\n` 换行，不发送 Markdown 围栏作为图的内容。
- 仅使用插件允许的分号格式 SGR：重置 `0`，粗体/暗淡/斜体/下划线/反色/删除线 `1/2/3/4/7/9` 及对应关闭码 `22/23/24/27/29`，基本与亮色前景/背景 `30–37/40–47/90–97/100–107`，默认色 `39/49`，256 色 `38/48;5;N`，RGB `38/48;2;R;G;B`。颜色分量为 `0–255`。电路图优先使用少量前景色，支持某种样式不代表应当使用它。
- 禁止非 SGR 控制指令，包括光标移动、清屏、OSC 超链接/标题/剪贴板、Tab 和 CR；SGR 中也不允许闪烁与隐藏文字。为每个着色片段显式重置，避免器件边框与下一条网络意外继承样式；不得依赖样式延续来表示连接。
- 每次输入最多 32 KiB（含 ANSI 序列）、200 行。优先缩短标签或拆成带完整网络标签的局部图，不截断电路。插件的窄窗口裁切只是保护终端布局，**被裁切的图不能视为交付完成**；重排并重新输出，或在用户加宽窗口后复核。
- 插件未加载、工具不可用、非 TUI 仅返回纯文本，或用户要求可复制的 Markdown 时，使用不含 ESC 的 `text` 代码块，保留标签与连接语义，并简短说明未展示颜色。不要自动安装、启用插件或更改终端主题。

## 4. 执行流程

1. **先列连接关系。** 在工作检查中列出电源、地、元件端子和它们所属的网络。未知引脚、极性或隔离关系影响结论时，先核对可靠来源或问一个聚焦问题，不猜测。
2. **设定固定列。** 确定主干行、支路列、器件边框和引脚出口。列坐标采用从 0 开始的显示列；一条竖直支路的导线、端口、极板中心和节点共享同一列。
3. **先布线，再放标签。** 在预留区域内放入中英文，按显示宽度补空格。文字不得占用导线、极板或节点；超出预留宽度时移动整个图块或扩大间距，不单独挤动一行。
4. **检查几何。** 对每条支路核对所有行的显示列；对框核对左右边界及上下端口；查断线、误连、错位、自动换行风险。可使用现有显示宽度工具或一次性本地检查，不必新增工具、依赖或测试套件。
5. **检查拓扑。** 从每个端子沿线追踪到目标网络，与第一步逐项比较；特别检查电容是否真正并联、输入与地是否短路、栅极或基极是否误连、续流二极管是否反向以及隔离地是否被合并。
6. **检查图文一致。** 核对元件编号、数量、取值、极性和说明。教学示例需声明简化边界；真实器件的引脚、EN/NC 和电容要求按对应数据手册处理，不能照搬通用框图。
7. **为已核对的网络配色。** 根据图要解释的路径选择少量颜色，同一网络的导线、节点和标签保持一致；器件本体不冒充网络。添加简短图例，再去除 ANSI 复核底稿，确保颜色没有改变几何、掩盖断线或替代文字含义。
8. **输出并保留证据边界。** 按 Pi ANSI 输出契约选择工具或纯文本回退，图后只补必要说明。工具调用成功不等于已经观察到终端颜色；分开记录文本几何、拓扑和实际显示证据。用户反馈错位、低对比度或裁切时，修正整张受影响图并重新输出，不只口头承诺。

本流程不自行授权文件覆盖、删除、发布或远程传输。涉及这些动作时，按宿主的授权与确认规则先确认再执行。

## 5. 经典示例

### 示例 A：LDO 输入、输出电容

以下为通用功能连接图，不是物理封装引脚图。省略型号相关的 EN 等端口；C1/C2 的有效容量与 ESR 必须满足所选 LDO 数据手册。

```text
                  U1 稳压器
             +----------------+
VIN --o------| IN         OUT |----o---- VOUT 输出
      |      |                |    |
      |      |    GND 接地    |    |
      |      +-------+--------+    |
     ---             |            ---
     --- C1          |            --- C2
      |              |             |
GND --o--------------o-------------o---- GND
```

- VIN：输入 / Input；VOUT：输出 / Output。
- C1：输入电容 / Input capacitor；C2：输出电容 / Output capacitor。
- 三条支路分别位于显示列 6、21、35；器件左右边框位于列 13、30。
- `    GND 接地    ` 占 16 个显示列，与器件内宽相同。
- 拓扑验收：VIN 连 IN 与 C1 上端；VOUT 连 OUT 与 C2 上端；C1/C2 下端与 U1 GND 同接 GND。VIN 和 VOUT 之间没有绕过 U1 的导线，VIN/VOUT 均未被导线直接短接到地。

### 示例 B：RC 低通滤波

```text
VIN 输入 --[R1]--o---- VOUT 输出
                 |
                ---
                --- C1 电容
                 |
                GND
```

- R1：串联电阻 / Series resistor；C1：并联电容 / Shunt capacitor。
- 中文出现在主干节点之前，也按显示列计数；节点、竖线和极板中心都在列 17，GND 标签中心也在列 17。
- 拓扑验收：VIN 经 R1 到 VOUT；C1 上端接 VOUT，下端接 GND；电容两极板之间没有贯通导线。负载如有，应接 VOUT 与相应回流网络。

### 示例 C：为 RC 图添加网络颜色

先复用示例 B 的已核对底稿。`VIN` 和 `VOUT` 在这里是信号，不是电源：输入用青色、输出用洋红，地线用默认色。颜色按本图含义选择，而不是看见 `VIN` 就机械套红色。电阻两端不是同一网络；R1、C1 本体保持默认色。

以下为 `render_ansi` 的工具参数示例；Agent 应实际调用工具，而非仅将 JSON 展示给用户。SOP 文件中保留可读的转义写法，不嵌入真实 ESC：

```json
{"text":"\u001b[96mVIN 输入 --\u001b[0m[R1]\u001b[95m--o---- VOUT 输出\u001b[0m\n                 \u001b[95m|\u001b[0m\n                ---\n                --- C1 电容\n                 |\n                GND\n\n\u001b[96m青色：输入信号\u001b[0m  \u001b[95m洋红：输出信号\u001b[0m  默认色：地与器件"}
```

- 去掉 SGR 与末尾图例后，字符图应与示例 B 逐字相同；节点及竖线仍位于显示列 17。
- 输出节点和电容上方导线同属 `VOUT`；电容两极板之间仍不画贯通导线，下端接 `GND`。颜色不代替电容符号或电气连接。
- 图例中的“默认色”同时用于地与非导电的器件外形，必须靠标签和线型区分；不能按颜色推断它们相连。

## 6. 异常与冲突处理

| 情况 | 处理 |
|---|---|
| 标签变长后边框或竖线错位 | 按新显示宽度重排受影响图块，并重新逐列检查；不能只加空格修补一行。 |
| 未知终端把歧义字符显示成不同宽度 | 先替换该符号为 ASCII；确需保留时请求截图或确认宽度设置，保留普通中文标签。 |
| 图过宽、插件提示裁切或交叉太多 | 缩短标签或拆分局部图，用一致的网络名连接；重新输出完整图，不把缺失右侧连线的裁切图当成完成，不悄悄改成图形文件。 |
| 地线颜色太暗或主题导致颜色难区分 | 提高对比度或改用默认前景，保留明确标签与图例；不修改全局主题，不以颜色作为唯一信息。 |
| 插件不可用或工具拒绝 ANSI | 不改用 Bash 绕过渲染或安全检查；按契约修正输入，无法渲染时输出无 ESC 的纯文本图并说明。 |
| 电气正确性与美观冲突 | 优先正确性与明确连接，再调整布局；必要时说明尚未确认的连接，不输出貌似完整的猜测。 |
| 实际器件信息不足 | 只给明确标注的通用示意，不声称可直接制板；需要具体接线时先核对型号和引脚资料。 |
| 无法查看目标终端渲染 | 完成显示列和拓扑检查，明确实际终端效果未观察；不把数学对齐当作截图验收。 |

## 7. 完成标准

- [ ] 图的主题与主要路径明确，供电/信号/回流及省略范围有必要标签；没有凭空补充器件规格。
- [ ] Pi 工具可用时实际调用 `render_ansi`；否则使用无 ESC 的独立 `text` 代码块并说明颜色回退。
- [ ] 仅使用普通空格、LF 与允许的 SGR；没有 Tab、其他终端控制序列、未处理的裁切或自动换行风险。
- [ ] 颜色与实际网络含义一致、图例简短、对比度足够；器件本体与导线可区分，去色后仍可读，不以同色替代电气连接。
- [ ] 中英文按显示宽度排版；所有支路、端口、极板中心和边框已逐列核对。
- [ ] T 接与汇接均有明确节点，交叉无歧义，文字未遮挡连接。
- [ ] 逐端子核对实际网络关系，没有断线、意外短路或跨接隔离边界。
- [ ] 极性、器件端子、元件编号与说明一致，功能图不冒充封装图。
- [ ] 验证结论准确区分显示列检查、电气拓扑检查和实际终端观察；未知事实已披露。
