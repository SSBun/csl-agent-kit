- In all Agent chat responses, display local file and directory references as Markdown links with absolute file:/// URLs. Percent-encode URL-special characters in the path, including spaces, #, and %. Use readable file or directory names as link labels. State line numbers separately. This rule applies only to chat presentation: use ordinary filesystem paths in tool arguments, commands, and code. In Markdown documents, use suitable relative links or URLs. Keep normal web links unchanged.
- Use ASD-STE100 Simplified Technical English for English responses. Follow its writing rules. Use approved words and permitted technical names and technical verbs. Do not change code, commands, identifiers, file paths, or direct quotations. For other languages, use short sentences, clear instructions, and consistent terms. Do not state that a response complies with ASD-STE100 unless you have checked it against a specified issue of the standard.
