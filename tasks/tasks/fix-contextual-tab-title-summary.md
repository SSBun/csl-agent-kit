# 让标签标题根据上下文生成有意义摘要

Status: Completed (2026-08-29 23:33)
Kind: Task

## Scope

- 确保 Pi 终端标签的每次标题更新都表达当前工作的明确主题，而不是复述或翻译最新用户回答。
- 不改变 Pi session metadata 或其他 Agent Hooks 行为。

## Target
- [x] T1: 当最新用户消息只是「确认」等无独立语义的简短回答时，标签标题不会直接使用该回答，而会结合相关会话上下文生成有意义的摘要标题
- [x] T2: 每个更新后的标签标题都具有明确含义并说明当前正在处理的工作；标题更新决策结合相关会话上下文，不把最新用户回答本身当作待总结的主题

## Plan

1. 让标题决策先识别完整会话中的当前工作，再判断最新消息是否改变、细化或仅回应这项工作。
2. 收紧有效标题边界，同时保留真正以确认、审批等为工作主题的标题。
3. 用回答、选择、任务细化和任务切换场景验证整体策略，并运行允许的质量检查。
