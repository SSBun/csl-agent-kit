# 讨论 Task Review 分级与强制审查边界

Status: Completed (2026-09-11 17:07)
Kind: Task

## Scope

- 讨论 Task Review 分级与强制自动审查的适用边界；本轮不修改现有 Review 机制。
- 仅记录用户确认的结论，不写入逐轮问答或未确认建议。

## Target
- [x] T1: 就 Task Review 是否分级，以及是否仅对复杂任务强制自动审查，形成用户确认的结论。

## Plan

1. 逐项澄清分级依据及强制审查的取舍，每次只讨论一个决策。
2. 用边界案例检验候选规则，明确免审条件及例外。
3. 汇总并请用户确认共同结论，记录结果及仍存在的局限。

## Decisions

- 用户以“Ok, execute this optimization”确认采用 R0／R1／R2 三级机制并授权后续实现。
- R0 无交付物变更免独立审查；R1 允许简单、低风险、影响明确且证据充分的变更免独立审查，包括符合全部条件的小范围逻辑修改；复杂、高风险或存在重要不确定性的变更进入 R2。
- R1 必须同时满足结果明确、影响可界定、后果低风险、验证证据充分；不能仅凭文件数、行数或主观复杂度免审。
- 任务保留等级、具体依据、内容版本和验证证据；相关变化重新判级。Reviewer 启动失败不能成为降级理由。
- R2 保留现有独立审查、修复循环和停滞保护；adversarial-review 仍仅由用户显式请求触发。程序只校验记录一致性，不宣称证明语义风险判断正确。
