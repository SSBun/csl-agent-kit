## 2026-07-19 区分取消流程与取消流程限制

- **Trigger:** 用户要求取消某个流程的轮次、次数、预算或上限。
  - **Rule:** 保留流程本身，只移除被点名的限制；除非用户明确说停止或取消整个流程，否则不得把限制变更解释成终止任务。
  - **Why:** “取消循环次数上限”改变的是终止策略，不是取消循环本身。
