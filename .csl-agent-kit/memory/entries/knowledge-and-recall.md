summary: 宽主题case组织、知识准入与当前正文检索；只保存当前知识，不保留来源、审查、历史或恢复副本。

- [2026-11-09] Memory适用于软件、Wiki及聊天等工作区；以长期关注的对象与问题形成宽主题，跨任务积累case，不默认按任务建文件。
- [2026-11-09] Memory仅保存当前有效知识文件：title、summary及带日期case，文件名提供身份；无来源、历史、审查、墓碑或恢复副本，不把它们转存别处。
- [2026-11-09] MUST 先读两级当前索引，再核对正文、条件与例外；线索不足时扩大措辞并搜索当前entries，不设固定命中上限。采信前 MUST 复查generation和候选文件hash，变化时刷新检索；索引过期或覆盖不足 MUST 说明，无命中不证明不存在。项目理解按需要覆盖职责、流程与验证信号，不默认全仓审计。
- [2026-11-05] 只收有证据、范围明确、稳定或有复核触发、能跨任务影响判断且比重建经济的知识；经验保留可识别触发、防护动作及可观察检查。可由源码、schema、测试、lint、CI或正式流程完全约束的问题，SHOULD 优先在那里修复，Memory只留仍需判断的部分。
- [2026-11-05] 用户纠正先应用当前工作，同类错误复发优先修订已有防护。前台负责读取应用，独立Memory Agent日常维护；两级自动维护仍服从明确限制。类型只作描述，不形成权限或检索排除；冲突依现行指令与权威判断，不按日期机械排序，检索不产生授权。
- [2026-11-09] 合并 MUST 保留独有条件、动作、检查及例外，语义相似本身不够；MUST NOT 仅因未使用而删除。MUST 先保存并回读替代知识，再修正当前正文引用及删除旧片；不能安全修正跨工作区引用时 MUST 保留。CAS冲突重读，错误不证明写入回滚。
- [2026-11-09] 每项目最多20个有效主题片、每片最多1000词，按Intl.Segmenter的zh/isWordLike统计。两级均只用index.md列当前摘要、正文链接和文件hash，不保留卡片、关系元数据或索引代际。正式契约查agent-memory技能及docs/memory.md。
- [2026-11-05] 隔离合并样例和候选上限、去重、冷却、入链保护的组件检查，不证明普遍语义准确率。基础元数据卡片不等于语义增强或召回提升；调度投递、开始执行、实现存在或授权，都不证明处理完成、当前激活或真实库整理效果。历史失败演示不定义恢复策略，实施审查不构成每次合并的审批。
- [2026-11-03] 本项目检索目标是简洁读取且不遗漏已记住的知识，MUST NOT 仅以少读或节省token认定成功；没有限定必须全量加载或使用某种索引结构，不推广为用户全局偏好。
- [2026-11-03] 索引先导比较4000字符分页与完整索引：同一合成语料、提示和工具，gpt-6-astra/medium、六类题单模板、50/200/1000文件规模；两组先读索引且未预注入首页。分页总体token较少、完整索引中位耗时较短，50文件时完整索引token略少；固定答案全通过不证明质量等价或分页普遍更优。困难语义召回、真实资料、深层矛盾、多版本、动态写入、生产注入及search-first未覆盖；条件变化时 MUST 重新比较，建议不构成实验或改造授权。
- [2026-11-03] 索引实验细节查.csl-agent-kit/tasks/artifacts/compare-memory-index-strategies/reports/pilot-report.md及相邻evidence/。统计以analysis.json为准，冻结pilot-summary.json的中位数定义有已披露偏差；总token含重复上下文和缓存读取，费用是SDK目录估价而非账单。历史实验不决定当前产品结构。
