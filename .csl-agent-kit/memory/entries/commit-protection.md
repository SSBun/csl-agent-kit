- [2026-11-10] 提交保护只读扫描暂存index的完整文件及二进制，区分大小写匹配由@code与-review拼接的保留子串；仓库根 `.csl-agent-kit/` 整树 MUST 豁免审查标记检查，目录外仍检查。会话报告检查器及技能已同步、语法/技能质量/目录边界检查通过，未跑单元或项目测试，本批未独立核验。字符串或示例不单独豁免；协议实现 MUST 用拆分/转义，MUST NOT 借此夹带说明。不识别无标记或编码变形；仅工作区/未跟踪文件有说明不阻提交。MUST NOT 清理或重暂存；失败时 MUST 修复或获得清理授权；隐式暂存、路径提交、复合提交等无法可靠检查形式 MUST 拒绝。不提供push历史、密钥或通用质量扫描。
- [2026-11-11] 在只检查可见 `git commit` 的范围内，shell检测 MUST 覆盖赋值、if/then、here-document后续、双引号内命令替换、反引号、前置重定向和time；MUST 保留单引号/普通文本非误报。包含可见提交入口但无法可靠检查的执行结构 MUST 拒绝；MUST NOT 将此拒绝策略用于不含可见 `git commit` 的其他Git命令。MUST NOT 首词放行、把双引号全当文本或遇<<停止。sh/bash/zsh/eval在正常与解析失败回退路径的语义 MUST 一致；MUST NOT 把包装字符串当普通文本；MUST 识别git bisect run git commit；MUST NOT 因外层为非commit子命令而放过其中可见的提交入口。丢弃空引号参数会让 `git -C "" commit -m safe` 的commit被当作-C参数值；仅识别标识符分隔符会漏掉 `<<123` 正文结束后的可见提交。入口分词 MUST 保留已开始但内容为空的参数；here-document检测 MUST 覆盖合法数字分隔符并继续扫描结束后的命令。核验时 SHOULD 覆盖这两种输入是否进入内容检查，以及正文中的commit文本是否误拦后续stash。会话静态复核确认这两个具体源码路径已修复，作者只读诊断报告通过；不代表here-document解析已完整覆盖。本批未独立核验源码或诊断，也未执行真实stash/commit，MUST NOT 将修复报告视为宿主行为或最终验收已通过。
- [2026-11-11] heredoc分隔符解析 SHOULD 执行不含展开的shell去引号，覆盖反斜杠、混合引用、Bash ANSI-C转义，并按引用状态判断正文展开。`<<\EOF`、`<<$'EOF'` 结束符均为 `EOF`；`<<$'EOF\x00'` 在Bash中于NUL截断为 `EOF`。原样保留反斜杠、美元符或NUL会吞掉后续commit；未闭合返回found=false可跳过inspectIndex。SHOULD 核对引用闭合、NUL截断、引号外拼接及后续扫描；SHOULD 成对诊断后续commit受检查、正文commit不误拦stash。fresh只读Reviewer静态确认每个ANSI-C段闭合时截断该段首个NUL及其后内容，再恢复普通拼接，真实结束行后继续扫描；反斜杠、混合引用、普通ANSI-C及非零hex修复保留，未发现回归。作者报告hex NUL后commit阻断、正文commit随后stash放行、octal NUL后拼接后缀的commit阻断，语法/技能质量零警告/差异/快照检查通过；Reviewer未复跑或独立重算hash，字节身份依赖作者校验。本批未独立核验；无单元/项目测试或真实Git变更，MUST NOT 据此认定宿主行为或最终验收通过。解析失败 MUST NOT 放行后续可见commit；非commit边界仍适用。
- [2026-11-06] Pi提交阻断 MUST 通过tool_call返回block/reason，异常也 MUST 阻断，且 MUST 实际加载对应版本并启用规则；仅覆盖可见Agent shell调用，不覆盖外部终端、GUI或任意脚本，不安装原生Git hooks。检查与提交无跨进程锁，不保证并发index/原生Hook修改；跨客户端强制需Git/CI且本地Hook可绕过。preview-clean只预览，删除前 MUST 核实注释语法、原文和任务归属；MUST 保留业务代码、普通注释及部分暂存；保留解释时 MUST 先存任务产物；发布 MUST 另获授权；标记为保留前缀加:begin/end及组/块ID，无安全注释形式时 MUST 用关联说明或聊天/PR。
