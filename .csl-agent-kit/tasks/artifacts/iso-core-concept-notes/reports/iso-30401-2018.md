# ISO 30401:2018：知识管理体系核心概念

## 标准身份与阅读边界

- 英文名称：Knowledge management systems — Requirements。
- 版次：2018年，第1版。
- ISO目录列有Amd 1:2022和Amd 2:2024；后者标题为Climate action changes。本文未逐条提炼修订件。
- 本文依据公开范围说明提炼组织知识管理的主要思路，未核对完整规范条文，不作为认证检查表。

## 核心概念

### 1. 管理对象是知识管理体系

标准针对组织如何建立、实施、维护、评审和改进有效的知识管理体系。适用范围不局限于某种规模或行业。

“体系”包含责任、工作方式、资源、评价和改进等相互关联的安排。一个知识库、搜索工具或文件目录只是支持手段，不能单独代表完整体系。

### 2. 知识需要服务于组织目的

决定保存什么知识之前，应理解组织要完成什么工作、哪些判断需要知识支持，以及关键知识缺失会造成什么影响。

文件数量增加不必然意味着知识管理改善。知识能够帮助人员理解问题、作出判断或完成工作，才体现其使用价值。

### 3. 知识不仅存在于文档中

知识可以体现在人员经验、协作、实践和已形成的工作方式中。把信息写下来有助于传播，但记录文本不等于完整转移了判断能力。

应用经验时仍需要理解情境和限制。其他团队成功采用的方法，未必能直接适用于当前环境。

### 4. 维护需要明确责任和支持条件

组织需要有能力维护知识，而不只是要求成员“多记录”。相关支持包括可用资源、人员能力、协作方式、适当工具，以及愿意分享和纠错的环境。

责任安排应有助于使用和更新知识，不应仅追求更多审批或元数据。

### 5. 知识需要持续使用、评审和改进

知识管理包括获得所需知识、使其能被适当主体使用，以及在环境或理解变化后维护它。过时知识如果仍被使用，可能比缺失知识更容易误导判断。

具体处理需要结合实际制度：纠正、替换或停止使用某项知识，并不自动意味着所有系统都必须删除相应历史记录。

### 6. 体系效果需要评价

评价应与组织目的和知识需求相关。可观察知识是否更容易找到、理解和正确使用，关键经验是否持续丢失，以及重复问题是否得到改善。

这些是解释性评价方向，不是本文从标准逐条提取的强制指标。指标的定义、采集方式和适用范围仍需单独确定。

## Memory应用：本地建议

- context帮助后续Agent理解项目背景和稳定约定。
- lessons保存能够影响未来判断的经验，保留触发条件、防护动作和检查。
- 新任务通常更新已有知识，不自动创建新文件。
- 用户纠正或新证据出现时，优先更新对应的当前案例，避免矛盾条目并存。
- 没有值得长期保留的知识时，允许零修改。
- 项目经验保持在项目作用域，不自动提升为全局偏好。
- 当前Memory只保存当前知识；任务记录和其他证据系统继续承担各自责任。

这些选择是本地Memory设计，不是ISO 30401规定的文件名、目录或删除策略。

## 示例

事件流水：

> 今天修复了Memory写入错误。

可复用经验：

> Memory返回索引更新失败时，正文可能已经保存；重试前先读取当前文件，避免重复写入或覆盖新的变更。

后者保留了触发条件、判断和防护动作。是否值得保留，还取决于该行为是否稳定、是否影响后续工作，以及是否已有更合适的权威载体。

## 常见误用

- 把知识管理等同于保存更多文本。
- 以文件数量、字数或写入频率代替实际效果。
- 认为写入文档就保证经验会被理解和应用。
- 将某次成功处理直接推广为普遍规则。
- 用一份Memory提示词宣称整个组织符合ISO 30401。
