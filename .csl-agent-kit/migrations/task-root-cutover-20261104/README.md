# Task目录迁移清单

本文记录准备时点，不是实时状态；实时切换状态见工作区存储标记及state.json。

所属范围：用户明确选定的工作区原tasks整树，内部分类不变；不包括Memory库和源码。

目标：.csl-agent-kit/tasks。共3322个文件、284个目录；60份可变记录需要链接重定位。逐项相对路径、大小、权限、前后SHA256和处理结果以manifest.json为准。

原文备份在before/tasks，待发布树在stage/tasks；执行apply后原树移入retired-tasks作为恢复材料，不自动删除。历史产物与审查证据原文保持不变。

中断时先检查存储标记及树状态；只对匹配清单续做或回滚，不能覆盖新的用户修改。
