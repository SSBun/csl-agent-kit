## Scope

仅细化上一轮第 3 项“中断恢复”的优化建议，交付方案而不实施。覆盖授权来源恢复、当前工作现场核对、外部副作用结果未知，以及本地记录中断后的诊断；不扩展为调度器、多会话租约、完整事件溯源或自动回滚系统。

## Target

- [ ] T1: 形成基于现有机制的中断恢复优化方案，明确授权来源、实际执行结果与未知状态的处理边界
- [ ] T2: 方案给出分阶段最小改动与验收条件，并保留授权、隐私、证据失效和防重复副作用约束

## Decisions

用户补充：实际开发中任务中断很少；意外中断时也没有机会补写任务信息。据此修正建议：当前不值得为恢复新增通用凭据、动作回执或周期性检查点。正常开发复用已有任务记录和真实产物；只有可控暂停时才补写交接信息，意外中断后从最近已存在的事实重新核对，接受必要的少量重分析成本。以下技术选项仅作未来出现具体恢复损失或高后果场景时的备选，不是当前实施建议，也不是用户对实施范围或执行目标的接受。

- 恢复分成三个独立问题：原授权及其当前适用性、实际产物和动作结果、下一步是否安全；任务 Status 和 Next action 均不能代替这三个判断。复用现有 Task/Plan/Result/Block、Topic freshness 与 check-evidence，不新增第二套任务状态。
- 若未来确需专项优化，可先强化只读恢复流程：加载 canonical record、当前宿主确认模式及真实会话分支；找回原始请求、完整 Target 展示与其后的用户回复；核对后续修订、对象、环境、范围和必要安全边界；再核对当前产物、Topic 和证据。无漂移且授权仍适用才继续，受影响的检查及审查正常失效，不能为了恢复免除它们。
- 授权来源使用宿主拥有的稳定会话/分支/entry 引用及必要内容摘要，仅是检索线索，不保存 confirmed=true 或可独立授予权限的接受标志。原文不存在、分支不适用或语义发生变化时不猜测；confirm 下按原协议重新核对，探索和当前 SOLO 仍走各自原有规则，历史 SOLO 不是用户接受证据。跨宿主能力未建立时明确降级，不虚构统一消息接口。
- Target 来源须兼容 assistant 文本和实际成功展示的 render_ansi 事件；展示工具调用参数本身不证明用户已看到或接受。现有 archive 的分支遍历可作实现参考，但其可见文本过滤排除工具调用/结果，不能直接作为完整授权恢复器，也不能自动归档整段会话。保留隐私边界，不把全量对话、凭据、私有推理写入仓库。
- 只有具体不可安全重复的外部动作确实需要时，才考虑增加最小证据回执。动作前记录同一逻辑操作的标识、目标身份、最少必要请求摘要及权威结果查询方式；动作后关联实际返回的远端 ID 或其他可核对结果。写前记录失败就不发起动作。记录 intent 不证明动作已发送，没有结果回执也不证明动作未发送；断线后默认结果未知，先只读查询权威端。
- 权威端已完成且与请求身份/内容匹配：补录回执并跳过重复动作，不能据此直接完成整个任务；权威证据能确认未发生副作用且授权仍有效：才按操作自身条件重试；状态未知或存在部分副作用：保持对应动作 Blocked，继续不依赖它的授权工作，Queue 不跳过当前阻塞 child。平台支持幂等键时重用原逻辑操作键并遵守有效期；不支持时不能承诺 exactly-once，内容相似或超时不是安全重试依据。
- 本地记录损坏与外部动作恢复分开。优先复用现有锁、原件备份、索引检查及 Topic pending marker，诊断不自动清理锁、覆盖并发修改或回滚已发布内容。现有 snapshot 主要保存身份而非文件备份，不能当作恢复未提交源码的保险。通用崩溃事务日志留到实际故障证据需要时再评估。

## Plan

1. 当前建议不实施专项恢复系统：不为低频中断增加每次正常任务的记录负担，也不把中断通知或退出 Hook 当作可靠的最后写入机会。
2. 可控暂停使用既有 Plan 恢复字段；意外中断只根据已经落盘的任务记录、代码与 Git diff、既有工具/会话记录和必要的外部状态重建事实，不假设刚完成的步骤已被记下。未来只有真实恢复成本或后果值得时，再选定上述备选能力。
3. 验收覆盖：接受后压缩且目标未变可恢复；分支切换不误用接受；后续修订/环境变化使旧依据失效；仅有摘要或丢失原文不伪造接受；ANSI Target 可定位实际展示；仅计划授权不转为实现；探索/SOLO 保留原分支；产物或 Topic 漂移触发必要重验；远端成功但本地回执丢失不重复执行；超时/部分成功/查询不可靠保持未知；intent 写入失败不执行；锁和索引中断不覆盖其他写入。
4. 实施前重新对齐具体阶段与最终系统行为；届时核实宿主 entry/渲染事件读取能力、真实只读审查能力及故障验证授权。当前未运行测试、真实交互回放或外部动作。
