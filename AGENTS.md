# Project Agent Rules

## Rule Changes

- After modifying agent rules, instructions, AGENTS.md, CLAUDE.md, skills, SOPs, or hooks, invoke `yao-meta-skill` to audit the changed rules before claiming the work is complete.

## Task Files

- Add new entries to the top of `tasks/todo.md` and `tasks/lessons.md`, directly under the file title, so the newest task or lesson is easiest to read.
